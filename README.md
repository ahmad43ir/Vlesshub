# VlessHub

🌐 Free VPN config hub — VLESS links, MTProto proxies, and VPN config files scraped from public Telegram channels.

## Download

⬇️ **[Latest Release](https://github.com/ahmad43ir/VlesHub/releases/latest)**

Install the APK on Android 6.0+ (API 23+).

## ⚠️ Source Code Policy

> **VlessHub is now closed source.**
>
> Starting with version 0.2.1, VlessHub is developed and distributed as closed source. This decision was made for security reasons — to protect user privacy and prevent misuse of the codebase.
>
> Earlier open-source releases (v0.1.0, v0.2.0) remain available in the [Releases](https://github.com/ahmad43ir/VlesHub/releases) section.

## Features

- **Links** — VLESS/V2Ray config links with TCP ping, copy, and export
- **MTProto** — Free Telegram MTProto proxy batches with copy, share, and open
- **Files** — VPN config files with download and open
- **Admin** — OTP-protected admin app for managing servers, proxies, and files
- **Ping** — Real TCP connect-time ping to test server speed
- **GeoIP** — Automatic country/flag detection for each server

## Tech Stack

- 🤖 **Android** — Kotlin + Jetpack Compose
- ⚡ **Backend** — Cloudflare Workers (JavaScript)
- 🗄️ **Database** — Supabase (PostgreSQL)
- 📡 **Scraper** — Python + Telethon (Telegram API)
- 📧 **Email** — Resend (OTP delivery)
